Protect your session. Respect privacy.

NyxWatch detects physical activity, locks macOS immediately and sends an event notification. It never reads typed keys, captures the screen or records the camera or microphone.

  • Activity detection from the system idle timer; no typed content
  • Immediate macOS lock without waiting for network delivery
  • Text alerts via your configured WhatsApp, Telegram, iMessage or LAN receiver
  • Text-only retry queue for the optional local WhatsApp bridge
Features

Protection, built in.

Detection runs on your Mac. Delivery uses the notification services you configure.

Privacy

Protection without recording.

No keylogging, screenshots, camera, microphone or face recognition. The Mac build requests none of those recording permissions.

Instant Arming

Arm in a keystroke.

Arm from any app with a single global shortcut, or enable optional Bluetooth Low Energy RSSI proximity auto-arming when you walk away.

⌘esc
Multi-Vector

Know when someone touches your device.

Detects activity from system idle time, USB device connections, volume mounts, lid closure and charger disconnection. It does not inspect USB contents or identify malicious devices.

Text Notifications

Alerts on your devices.

Event type and timestamp are sent to your chosen services. WhatsApp, Telegram and iMessage use their own infrastructure; a LAN receiver is also supported.

Resilient Privacy

Automatic retry when you reconnect.

The optional local WhatsApp bridge retries queued text alerts after a delivery failure. Locking happens immediately even when the network is unavailable.

Install NyxWatch

The Mac installer below is the privacy-focused release. Other platform sources are separate prototypes.

Install on your Mac

Download the Mac installer, open the DMG and drag NyxWatch to Applications. For macOS 13 or later, on Apple Silicon and Intel. Source code is available on GitHub.

Download for Mac (.dmg) View source on GitHub
macOS Drag and drop

  1. Download and open the DMG

    Click Download for Mac, then open NyxWatch.dmg from Downloads. A window with NyxWatch and the Applications folder appears.

  2. Drag NyxWatch to Applications

    Drag the NyxWatch icon onto Applications in that window. Wait for the copy to finish. If you are updating, quit NyxWatch first and choose Replace when macOS asks.

  3. Open NyxWatch

    Open Applications in Finder and double-click NyxWatch. Look for its N logo in the menu bar and on the floating button. Protection starts off.

  4. Apple notarization

    This installer is signed with Developer ID and notarized by Apple.

    Apple’s first-launch guide
Windows Run with Python

  1. Install Python

    Open the official Python download page and install Python 3. When the installation is finished, close the installer.

    Get Python for Windows

  2. Open PowerShell in the project folder

    Open the extracted NyxWatch folder in File Explorer. Click the address bar, type powershell and press Enter. Then paste the line below and press Enter.

    cd cross-platform/desktop

  3. Prepare NyxWatch

    Copy and run each line in order. Wait for each one to finish before you paste the next. The first creates a local Python environment and the second installs the packages.

    py -3 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

  4. Start in Flag mode with protection off

    Run the line below. Look for Armed: False in PowerShell. To close NyxWatch, press Ctrl + C in the same window.

    .\.venv\Scripts\python.exe nyxwatch_desktop.py --mode flag
Linux Run with Python

  1. Make sure Python is ready

    Open Terminal and run the first line. If Python or venv is missing on Ubuntu or Debian, run the second line and wait for it to finish.

    python3 --version
    sudo apt install python3 python3-venv

  2. Open Terminal in the project folder

    Open the extracted NyxWatch folder in your file manager. Right-click an empty spot and choose Open in Terminal. Then run the line below.

    cd cross-platform/desktop

  3. Prepare NyxWatch

    Copy and run each line in order. Wait for each one to finish before you paste the next.

    python3 -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt

  4. Start in Flag mode with protection off

    Run the line below. Look for Armed: False. To close NyxWatch, press Ctrl + C. Input detection can be limited on Wayland.

    .venv/bin/python nyxwatch_desktop.py --mode flag
